## Decision diary and mistakes

The first manifest lookup assumed the wrong plugin-manifest directory; reading the
actual two manifests resolved it. Initial batched source output was too large and
was re-read in smaller groups. A filename glob assumed a nonexistent source file;
inspection continued through actual filenames. These are operator mistakes, not
product defects.

The independent continuation caught a more useful mistake: a finding combined
entry-point and provider-handler behaviour but cited only the entry point. Revision
003 added the missing source attribution while preserving the original annotation.
Validation alone had not caught this evidential weakness. Preserve that distinction
in any article; do not turn successful validation into a research-accuracy claim.

The model-catalog endpoint calls runtime inspection. We left it uncalled because
a GET request is not automatically passive. UI access and target access also proved
separate: starting Labs made its UI available without resolving SSH authentication.
The existing Lab UI exposed earlier chat/history automatically; those reports were
not adopted as new observations or substituted for this run's saved artifact.
