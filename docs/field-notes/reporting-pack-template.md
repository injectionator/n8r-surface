# Installment reporting pack template

Copy for each installment. This is source material for injectionator-website,
not article copy. Leave unknowns and missing captures explicit.

## Identity and question

- Installment ID, working title, date, author/operator and linked issue:
- Reader's question, why it matters, intended outcome:
- Status: Planned / In progress / Blocked / Verified source pack / Handed off / Published.
- Exact source, skill and host revisions; environment and access limits:
- Initial state, actual input, expected observable result:

## Actual sequence

| Event | Actual prompt or command | Observed output / exit | Evidence reference | Meaning and limits |
| --- | --- | --- | --- | --- |
| Pending | Not run | Not observed | None | No claim yet. |

## Decision diary and mistakes

Record short contemporaneous reflections and label retrospective additions.
For each useful event: expectation, surprise, decision, reason, consequence,
correction/retry, verification and unresolved cause. Distinguish operator error,
product gap, environment issue and unknown cause; do not guess attribution.

## Verified result and repeatable companion

- What changed; what did not; what was newly learned rather than newly changed:
- Independent claim checks and saved-file readback, with evidence references:
- Human task list: prerequisites, exact interaction, expected visible result,
  readback, variable values, failure criteria and cleanup:
- Agent rehearsal versus human acceptance: Pass / Fail / Blocked and evidence:
- Material limitations and next real question:

## Media and excerpt manifest

| Asset | Actual event / capture date | Claim supported | Caption / alt text | Redactions / rights | State |
| --- | --- | --- | --- | --- | --- |
| Pending | None | None | None | Review needed | Not captured. |

Keep private originals separate from approved publication assets. Identify exact
commands and output excerpts worth showing; explain publication substitutions.
Record video availability and editing notes without implying it was recorded.

- Verified story beats and useful lesson:
- Possible opening and next question, explicitly editorial suggestions:
- Facts/quotes that must remain exact; claims the evidence does not support:
- Source-pack revision and approved asset references:
- Website changes, owner, state and links:
- Reviewer and publication-safety status:
- Website article PR, publication URL and later corrections:
