## Human task list

Prerequisites: candidate 0.1.13 installed, Node 22/24/26 and readable selected
sources; a new writable Surface folder outside the source checkout. The maintainer
provides the exact candidate revision/digest and rehearsal output separately.

- [ ] Open a fresh chat with the installed Researcher and the selected source.
  Ask: “Explain the AI-relevant paths in this source. Save the Surface and maintain
  an investigation journal in this folder as you go. Show me what to inspect next.”
  Expect an initial plan, useful partial findings and openable journal/map/brief.
- [ ] Inspect the map. Possible paths and selected paths must look different.
  Open a relationship's evidence; unknown selection must not be called absent.
  Selection must not be called observed runtime use without dated evidence.
- [ ] Redirect: “Pause that path and investigate authentication first. Keep the
  deferred work and explain what access would help.” Expect a recorded diversion,
  deferred reason, new next steps and a new revision preserving earlier files.
- [ ] In another fresh chat supply only the latest BOM and source access. Ask:
  “Continue this Surface. What did I choose, what remains uncertain, and what
  should we investigate next?” Expect recovery of the choices, evidence and
  investigation state without requiring a native sibling or old chat.
- [ ] Report **Pass / Fail / Blocked**, the interaction, candidate revision and
  relevant output paths. Fail for lost decisions, invented bindings, changed old
  files or missing state; Blocked for inaccessible sources/runtime. Keep source
  data private. Retain outputs until reviewed; cleanup is only the disposable run.
